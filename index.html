Aegires-gen3 Compatible

End-to-End Encrypted Text, Media & Discord CLI

aegires-cli is a zero-C-dependency, cross-platform Rust terminal client implementing the Aegires-gen3 dcenc2 protocol. Derive your Argon2id key once per session, encrypt or decrypt messages and 64 KiB streaming media files, or log in to Discord to auto-decrypt everyone's messages in real time.

Argon2id (64 MiB, 3 passes) AES-128 / 192 / 256-GCM Streaming Media Encryption RAM-Only Zeroized Keys Termux · Linux · macOS · Windows

One Session, Zero Disk Writes

Enter your passphrase once on launch. Keys and tokens stay strictly in RAM and are wiped via zeroize on switch or exit.

Auto-Detect Author & Channel

Log in with a Discord token to automatically fetch each message's real author ID and decrypt chats and attachments effortlessly.

Universal Rust Build

Pure Rust crates with no OpenSSL or system library headaches — compiles cleanly on Android Termux, Linux, macOS, and Windows.

1. Build & Install

Select your platform below to compile and install aegires-cli from source.

2. Starting a Session & Managing Keys

Launching aegires-cli asks for your Argon2id passphrase once. Input is intentionally hidden (no characters or * are echoed) so your passphrase never leaks into terminal scrollback.

Session Unlock
$ aegires-cli --login Aegires-gen3 CLI (dcenc2) — Pure Rust Cross-Platform E2EE Keys & Discord tokens stay in RAM only and are wiped on exit. Argon2id passphrase: (type or paste — stays invisible, then press Enter) Deriving 256-bit key (Argon2id 64 MiB, 3 passes)... done in 202 ms. Discord token (hidden input): (paste token, then press Enter) Verifying token with Discord... logged in as Alice (@alice, ID: 987654321098765432)

Switching Keys Mid-Session

You never have to restart the app to switch keys. The old key is immediately overwritten and zeroized in RAM:

Key Switching Commands 
# Switch to a new standard user passphrase
key

# Switch to a context-bound passphrase (custom salt: dcenc2|ctx|<context>)
key --ctx forced|123456789012345678

# Load a built-in forced channel key automatically
forced 123456789012345678

# Wipe key + token from RAM and quit (next launch requires re-entering password)
exit
Termux Pasting Tip Long-press anywhere on the Termux terminal and tap Paste at the hidden passphrase or token prompt, then press Enter. The line stays blank by design even after pasting.

3. Discord Mode (Auto-Detect IDs & Decrypt Everyone)

Aegires cryptographically binds every ciphertext to both the Channel ID and the Author (Sender) ID so messages cannot be replayed across channels or forged under another user. Logging in with your Discord token lets aegires-cli resolve every message's real author ID automatically.

Step-by-Step Workflow

  1. Run login (or launch with aegires-cli --login). Your own Sender ID is configured automatically.
  2. List your DMs with dms, or browse servers with guilds → channels <guild_id>.
  3. Switch to any channel using open <channel_id>. It immediately loads and decrypts the latest 10 messages from everyone.
  4. Load more history anytime with r 25 (up to 50 messages), or send an encrypted reply with s Hello!.
Browsing & Auto-Decrypting
aegires[alice@0]> dms DMs (use `open <channel_id>`): 123456789012345678 @Bob aegires[alice@0]> open 123456789012345678 Active channel -> 123456789012345678 [🔓 Bob] (AES-256-GCM): Meet at 8 PM! [🔓 Alice] (AES-256-GCM): On my way. [Attachment #1] photo.jpg.aeg (1.42 MiB) — run `dl 1` to decrypt aegires[alice@123456789012345678]> s Sounds good! Sent [AES-256-GCM | id:139900112233445566]

Smart Direct-Paste Shortcuts

At the main prompt, you can paste directly without typing a command prefix:

  • Paste a Discord message link (https://discord.com/channels/.../.../...): automatically fetches that exact message, reads its author ID, and decrypts it.
  • Paste a §... ciphertext: decrypts immediately (and if you are logged in with a channel open, scans the last 50 messages to match the real author ID automatically).

4. Live Chat & Encrypted Media

Run chat after opening a channel to enter real-time terminal chat. Incoming messages from others decrypt automatically as they arrive, and any normal line you type is encrypted and sent directly.

Inside Live Chat Mode 
# Start live chat in the currently open channel
chat

# Type any text and press Enter to encrypt & send:
Hey, check out this encrypted image!

# Slash commands available inside chat mode:
/file "/sdcard/Download/photo.jpg" Optional encrypted caption
/dl 1 "/sdcard/Download/restored.jpg"
/key
/q

Uploading & Downloading Encrypted Attachments

Files are streamed in 64 KiB authenticated chunks (Aegires file format v3) so large videos and photos use minimal memory:

Discord Media Commands (from main prompt) 
# Encrypt and upload a photo or video directly to the open channel
sendfile "/sdcard/Download/clip.mp4" "Check this out"

# Download and decrypt Attachment #1 listed by `r` or `chat`
dl 1

# Download and decrypt directly to a custom path
dl 1 "/sdcard/Download/clip_decrypted.mp4"

5. Offline / Local Mode (No Discord Login Needed)

You can encrypt and decrypt text or local files completely offline. Set your Channel ID and Sender ID once per session, or override them per command with -c, -s, and -p.

Offline Text & Local File Encryption 
# Configure defaults for the current session
set channel 123456789012345678
set sender  987654321098765432
set preset  aes256

# Encrypt a text message -> outputs §base64
e Secret message for the channel

# Decrypt your own message
d §Ir2c9ROK...

# Decrypt a message sent by someone else (override sender ID with -s)
d -s 111222333444555666 §IrG4iQyY...

# Encrypt a local image, video, or archive (creates photo.jpg.aeg)
ef "/sdcard/Download/photo.jpg"

# Decrypt a local .aeg file (auto-strips .aeg or writes to custom path)
df "/sdcard/Download/photo.jpg.aeg" "/sdcard/Download/restored.jpg"

# Decrypt a file created by someone else
df -s 111222333444555666 "/sdcard/Download/video.mp4.aeg"

e [-c] [-s] [-p] <text> Offline Encrypt plaintext into a §-prefixed Base64 ciphertext string.
d [-c] [-s] <§cipher> Offline Decrypt a § ciphertext (auto-detects AES preset; auto-matches author when logged in).
ef [-c] [-s] [-p] <in> [out] Offline Encrypt any local file or media in 64 KiB chunks. Defaults output to <in>.aeg.
df [-c] [-s] <in> [out] Offline Decrypt any local .aeg file. Partial output is deleted automatically if auth fails.

forced <channel_id> Session Derive and activate a built-in forced channel key and switch channel ID.

status / info Session Display logged-in account, key mode, preset, max message bytes, channel, and sender.
exit / quit / q Session Zeroize master key and Discord token from RAM and exit.

7. Protocol & Security Architecture

aegires-cli is wire-compatible with Aegires-gen3 (dcenc2). Receivers read the preset directly from the header byte, so all three presets interoperate freely in the same channel.

Preset Index Key Size GCM Tag Pad Block Max Text Payload
AES-128-GCM 0 16 bytes (128-bit) 12 bytes (96-bit) 16 bytes 1,455 bytes
AES-192-GCM 1 24 bytes (192-bit) 14 bytes (112-bit) 32 bytes 1,439 bytes
AES-256-GCM 2 32 bytes (256-bit) 16 bytes (128-bit) 64 bytes 1,407 bytes
  • Master Key Derivation: Password is Unicode NFKC-normalized and hashed via Argon2id v1.3 (m = 65536 KiB, t = 3, p = 1, 32-byte output) using salt dcenc2|user-key|v1 (or dcenc2|ctx|<context>).
  • Per-Message / Per-File Keys: Every item generates a fresh 16-byte OS CSPRNG salt and derives unique key + nonce material via HKDF-SHA256 bound to (kind, preset, channel_id, sender_id).
  • Authenticated Associated Data (AAD): Header byte, salt, and context info are authenticated by AES-GCM, preventing replay across channels or authors.
  • Streaming Media (v3): Files are encrypted in 64 KiB chunks with a 12-byte nonce composed of 7B HKDF prefix || 4B big-endian chunk counter || 1B final flag, detecting chunk truncation, dropping, or reordering.
  • Memory Hygiene: Passphrases, derived master keys, per-item OKM, plaintext buffers, and Discord tokens are cleared using zeroize on drop.
Discord Token Security Reminder Never share your Discord token, commit it to Git, or paste it in screenshots. Automated user-token requests against Discord's API may violate Discord's Terms of Service—use responsibly and avoid aggressive polling.

8. Troubleshooting

Decrypt error: Authentication failed (wrong key, channel, sender, or tampered data)

Every ciphertext is bound to four things: Passphrase, Key Context (user key vs. forced channel key), Channel ID, and Sender (Author) ID. If someone else sent the message and you are offline, pass their user ID with d -s <author_id> §...—or run login and open <channel_id> so the CLI detects their ID automatically.

Messages show "[🔒 Author] (wrong key or forced channel key needed)"

Either your active passphrase differs from the sender's, or the channel uses a context-bound forced key. Run key to switch passphrases, or forced <channel_id> / key --ctx forced|<channel_id>, then run r again.

HTTP 401 Unauthorized when running login

Your Discord token is invalid, expired, or has extra characters around it. Make sure you copy the raw token without a Bot prefix or extra whitespace and paste it cleanly at the hidden prompt.

Cannot open files in /sdcard/Download on Termux

Run termux-setup-storage once in Termux and grant storage permission. Always wrap paths containing spaces in double quotes, e.g. ef "/sdcard/Download/my photo.jpg".
